#### FurBot is a web-based chatbot designed to help dog owners with everyday needs. Whether you're looking for dog-friendly parks, restaurants, cafes, grooming salons, vet clinics, or supplies, FurBot has you covered! Built with Python and NLP, FurBot provides quick and accurate responses to enhance your pet-friendly lifestyle.

Now with Pet Profile Management and Reminders, FurBot allows users to:
✔ Create and manage pet profiles (store pet details like breed, age, and medical history).
✔ Set reminders for vet visits, vaccinations, and grooming schedules.
✔ Receive automated notifications to ensure your pet gets the best care.

Built with Python and NLP, FurBot provides quick and accurate responses to enhance your pet-friendly lifestyle.
